  CVE-2025-9501 — W3 Total Cache < 2.8.13 unauthenticated PHP command injection

          processed, mfunc parser evaluates injected PHP → arbitrary code execution

HOW IT INTEGRATES WITH PENTEST-AGENT:
================================================================================

  Phase: FINGERPRINT
    └─ Probes /wp-content/plugins/w3-total-cache/readme.txt
    └─ Detects W3 Total Cache version

  Phase: SCAN
    └─ Checks version against Wordfence vulnerability feed
    └─ Reports CVE-2025-9501 if < 2.8.13

  Phase: MATCH
    └─ Consults wp_recipes.find_recipes("w3-total-cache")
    └─ Identifies CVE-2025-9501 as in-scope candidate for this version

  Phase: EXPLOIT
    └─ Calls exploit(base_url, candidate, http)
    └─ Dispatches on mode="w3-comment-injection"
    └─ Executes _exploit_w3_comment_injection()
    └─ Returns planted webshell path: /wp-content/plugins/w3-total-cache/wsh_<token>.php

  Phase: VERIFY
    └─ Tests planted shell with ?c=id
    └─ Confirms command execution (uid=33(www-data) etc)
    └─ Optionally cleans up (--no-cleanup to keep)
